# Wavelength Frontend

This is a starter frontend for the Wavelength music-player project.

## Files
- `index.html` - webpage structure
- `css/style.css` - visual design
- `js/app.js` - basic navigation and starter button interaction
- `assets/images/` - place artwork/images here later
- `assets/icons/` - place icons here later

## Run it
1. Open the `Frontend` folder in Visual Studio Code.
2. Install the **Live Server** extension if it is not already installed.
3. Right-click `index.html` and choose **Open with Live Server**.

## Current limitations
- The play button currently changes its symbol only; it does not play audio.
- The C++ backend is not connected yet.
- Playlist, recent-history, and queue sections are placeholders.
